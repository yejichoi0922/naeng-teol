# 🍳 냉털 (냉장고 털기 레시피)

이 프로그램은 **냉장고에 남아 있는 재료를 활용하여 다양한 레시피를 추천받고 싶은 사용자**를 위한 프로그램입니다.

## ⭐ 주요 기능

### 🥕 재료 입력하기

현재 냉장고에 있는 재료를 입력해주세요.

### 🍽️ 레시피 추천받기

입력한 재료를 바탕으로 만들 수 있는 요리를 추천해드립니다.

### 📖 레시피 확인하기

추천된 요리의 재료와 조리 방법을 확인해보세요.

### ♻️ 식재료 활용하기

남은 식재료를 효율적으로 사용하여 음식물 쓰레기를 줄여보세요.

### 👩‍🍳 즐거운 요리 시작하기

원하는 레시피를 선택하고 맛있는 요리를 만들어보세요!
